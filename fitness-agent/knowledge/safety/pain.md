# 训练中出现疼痛怎么办

## 要点

先分清两种感觉：训练后 1–3 天出现的、范围较大的酸胀属于延迟性肌肉酸痛；出现在关节、局部、呈尖锐刺痛或伴随无力的，是需要立刻停止的信号。

## 分级

- 可以继续：训练后出现的对称性酸胀，活动开略有缓解，不影响正常动作。
- 降低强度：动作中出现酸胀但可以控制，减轻重量或范围后消失；本次训练降到无痛范围，下次先做动作调整。
- 立即停止：关节内部刺痛、卡住感、弹响伴疼痛、局部痛点明确、肢体无力或发麻。

## 怎么做

1. 出现停止级信号时，结束该动作，不要「再来一组试试」。
2. 记录疼痛位置、出现动作、持续时间，便于就医时描述。
3. 48 小时后仍无缓解，或出现肿胀、发热、夜间痛，应就医评估。
4. 恢复训练时从无痛范围开始，逐步加量，而不是直接回到原来的重量。

## 危险信号

放射性疼痛（沿腿或手臂向下串）、肢体麻木无力、关节急性肿胀、夜间疼痛加重，均需尽快就医。

## 相关

有既往伤病或长期疼痛史的人，应在开始训练前咨询医生或康复专业人员，并按允许的动作范围训练。
