# 哑铃单臂划船

## 动作目标

强化背部与肩胛控制，对久坐导致的圆肩、含胸有直接帮助。单臂支撑让腰部负担更小。

## 执行步骤

1. 一手一膝支撑在长凳上，另一侧手持哑铃自然下垂。
2. 背部保持水平，肩胛先微微后收。
3. 呼气，把哑铃拉向髋部方向，肘部贴近身体。
4. 顶点停顿半秒，吸气缓慢下放至手臂伸直。

## 训练量建议

- 每侧 3 组，每组 10–12 次，组间休息 60 秒。

## 常见错误

- 靠身体旋转甩起重量
- 耸肩，用斜方肌上束代偿
- 拉到胸口位置而非髋部

## 替代动作

- 弹力带划船（`band_row`）
- 高位下拉（`lat_pulldown`）

## 停止条件

肘内侧或肩关节出现疼痛时降低重量或停止。
