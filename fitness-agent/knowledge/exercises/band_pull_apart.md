# 弹力带拉开

## 动作目标

强化肩后侧与上背，对抗久坐含胸的姿势。可作为训练前的肩部激活，也可作为独立的体态训练。

## 执行步骤

1. 双手握带，掌心相对，手臂前伸与肩同高。
2. 肩胛先向后收，再向两侧把带子拉长。
3. 拉到手臂与身体呈一条直线即可，停顿 1 秒。
4. 缓慢还原，保持张力不要弹回。

## 训练量建议

- 3 组，每组 12–15 次，每天可做。

## 常见错误

- 耸肩
- 腰椎后仰借力
- 带子松垮，没有持续张力

## 替代动作

- 哑铃单臂划船（`dumbbell_row`）
- 面拉（`face_pull`）

## 停止条件

肩部不适时减小幅度；检查弹力带是否老化破损。
