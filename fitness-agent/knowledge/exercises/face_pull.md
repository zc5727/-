# 面拉

## 动作目标

训练肩袖与肩胛后侧，属于对肩关节有保护价值的补充动作，常用于上肢训练日的收尾。

## 执行步骤

1. 把带子或绳索固定在面部高度。
2. 双手握带，手臂伸直，掌心向下。
3. 把带子拉向面部两侧，肘部打开向后。
4. 顶点停顿，缓慢还原。

## 训练量建议

- 3 组，每组 12–15 次，重量偏轻。

## 常见错误

- 重量过大导致躯干后仰
- 肘部下垂，变成划船
- 幅度过小

## 替代动作

- 弹力带拉开（`band_pull_apart`）
- 哑铃单臂划船（`dumbbell_row`）

## 停止条件

肩关节出现疼痛时停止并咨询专业人员。
