# 箱式深蹲

## 动作目标

用一个真实存在的板凳或箱子限定下蹲深度，解决新手「蹲不下去」或「越蹲越浅」的问题，同时保护腰椎。

## 执行步骤

1. 把稳固的箱子或凳子放在身后，高度让大腿在坐下时大致与地面平行。
2. 站到箱子前，双脚与肩同宽。
3. 臀部向后坐，直到轻轻触到箱面，不要重重砸下去。
4. 触箱后停顿半秒，保持腰背挺直，然后站起。
5. 整个过程中膝盖方向与脚尖一致。

## 训练量建议

- 每次 3 组，每组 8–12 次，组间休息 60–90 秒。
- 稳定后可以把箱子换低一档，而不是急着加重量。

## 常见错误

- 坐下时整个人松垮地瘫到箱子上，失去张力
- 触箱后借助弹跳起身
- 膝盖内扣

## 替代动作

- 徒手深蹲（`bodyweight_squat`）
- 坐姿起立（`seated_to_stand`）

## 停止条件

下蹲过程中腰部出现放射性疼痛或腿麻，立即停止；这类信号需要先就医而不是继续练习。
