# 哑铃侧平举

## 动作目标

针对肩中束的孤立动作，是肩部宽度与体态改善的常用动作。重量轻、次数高是它的正确打开方式。

## 执行步骤

1. 站立，双手持哑铃置于身体两侧，肘部微屈。
2. 向两侧抬起手臂，到与肩同高即可。
3. 顶端小指略高于拇指，避免肩内旋。
4. 用 2–3 秒缓慢下放。

## 训练量建议

- 3 组，每组 12–15 次，重量宜轻。
- 不要用甩动或借力来抬更大重量。

## 常见错误

- 靠身体晃动借力
- 抬得过高，超过肩平面
- 耸肩

## 替代动作

- 弹力带拉开（`band_pull_apart`）
- 哑铃肩推（`dumbbell_shoulder_press`）

## 停止条件

肩关节出现夹挤样疼痛时降低幅度或停止。
