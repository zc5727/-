# 俯卧撑

## 动作目标

最经典的自重推力动作，同时训练胸、肩前束、手臂后侧与核心。做不动标准版本时，降低难度比勉强硬撑更有效。

## 执行步骤

1. 双手撑地略宽于肩，手腕在肩关节正下方稍前。
2. 双脚并拢或与髋同宽，收紧腹部与臀部，身体成一条直线。
3. 吸气，屈肘下降，大臂与躯干约呈 45°，胸口接近地面。
4. 呼气，掌心发力推起，顶端肘部保持微屈不要锁死。

## 训练量建议

- 新手 3 组，每组 6–12 次；做到几乎力竭前留 2 次余力。
- 做不动时改做跪姿俯卧撑或上斜俯卧撑。

## 常见错误

- 屁股翘起或腰部塌下
- 肘部完全外展成 90°，肩关节压力大
- 下降幅度过小，只做上半程

## 替代动作

- 跪姿俯卧撑（`knee_push_up`）
- 上斜俯卧撑（`incline_push_up`）

## 停止条件

手腕或肩关节出现刺痛时立即停止，改用上斜版本或拳撑。
