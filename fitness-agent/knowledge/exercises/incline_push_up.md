# 上斜俯卧撑

## 动作目标

把手撑在台阶、桌面或长凳上，通过抬高支撑点按需调节负荷。是老少皆宜、最容易自行控制强度的推力动作。

## 执行步骤

1. 双手撑在稳固平台边缘，略宽于肩。
2. 身体从脚到头保持一条直线，脚尖着地。
3. 屈肘下降，胸口靠近平台边缘。
4. 推起回位，全程核心收紧。

## 训练量建议

- 3 组，每组 8–15 次。
- 平台越低越难，稳定后逐步降低高度。

## 常见错误

- 平台不稳固（务必确认不会滑动）
- 身体塌腰
- 下降幅度不足

## 替代动作

- 跪姿俯卧撑（`knee_push_up`）
- 俯卧撑（`push_up`）

## 停止条件

肩前侧出现刺痛时停止，改练其他推力动作。
