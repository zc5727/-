# 死虫

## 动作目标

在四肢移动的同时保持腰椎不动，训练真正的核心稳定。对腰部敏感的人群比仰卧起坐友好得多。

## 执行步骤

1. 仰卧，双臂指向天花板，髋膝各屈 90°。
2. 腰部轻贴地面，肋骨下沉。
3. 缓慢伸出一侧手臂与对侧腿，接近地面但不碰地。
4. 收回后换另一侧，全程腰不离地。

## 训练量建议

- 3 组，每侧 8–12 次。
- 腰一旦离地就是幅度过大，缩小幅度即可。

## 常见错误

- 腰部拱起离地
- 动作过快靠惯性
- 憋气

## 替代动作

- 鸟狗（`bird_dog`）
- 平板支撑（`plank`）

## 停止条件

腰部出现不适或无法维持贴地时立即缩小幅度或停止。
