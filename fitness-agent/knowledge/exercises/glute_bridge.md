# 臀桥

## 动作目标

唤醒长期久坐而失活的臀肌，同时让腰部学会在不动的情况下保持稳定。很多人的腰酸，根源是臀肌不干活、腰在代偿。

## 执行步骤

1. 仰卧屈膝，双脚踩地与髋同宽，脚跟距臀部约一掌。
2. 呼气，脚跟发力把髋部顶起，直到肩、髋、膝大致成一条直线。
3. 顶点主动夹紧臀部，停顿 1–2 秒。
4. 吸气，用 2–3 秒缓慢落下，臀部接近地面但不完全放松。

## 训练量建议

- 3 组，每组 12–15 次。
- 进阶可在髋部加负重或改为单腿臀桥。

## 常见错误

- 用腰发力把身体拱起来，顶峰时腰部酸痛
- 脚放太远导致腘绳肌抽筋
- 顶点没有停顿，靠惯性上下

## 替代动作

- 髋铰链（`hip_hinge`）
- 鸟狗（`bird_dog`）

## 停止条件

顶起时腰部出现刺痛或腿部发麻，立即停止。
