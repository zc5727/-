# 组间休息

## 要点

组间休息的长短决定了下一组能维持多大的重量和动作质量。休息不足会让后面的组变成练心肺而不是练力量。

## 怎么做

1. 大肌群复合动作（深蹲、硬拉、划船）：休息 90–150 秒。
2. 中小肌群孤立动作（弯举、侧平举）：休息 45–90 秒。
3. 核心与静力动作：休息 30–60 秒。
4. 判断标准：呼吸基本平复、能说完整句子，就可以开始下一组。

## 常见误区

- 严格掐表 30 秒，导致后面几组重量掉一半
- 休息时刷手机坐到身体完全冷掉
- 只练小肌群却休息 3 分钟，训练效率低

## 什么时候该调整

训练时间紧张时，缩短休息是可行的，但要相应降低重量与组数，而不是硬撑同样的量。
